# SkillBridge AI: Capstone Technical Documentation

## 1. Executive Summary

**SkillBridge AI** is a production-grade SaaS platform designed to modernize career coaching for the Singapore workforce. By integrating real-time labor market data with advanced Generative AI, it provides personalized, unparalleled career guidance. The platform utilizes a fully **Serverless Architecture** on AWS, demonstrating high scalability, operational efficiency, and a **~95% cost reduction** compared to traditional containerized solutions.

---

## 2. Technical Architecture

The system leverages a cloud-native, event-driven architecture designed for zero idle costs.

```mermaid
graph TD
    User((User))

    subgraph Frontend_Hosting [Frontend Hosting]
        CF[CloudFront CDN]
        S3[S3 Bucket<br/>(React/Next.js)]
    end

    subgraph Backend_Services [Serverless Backend]
        APIGW[API Gateway<br/>(HTTP API)]
        Lambda[AWS Lambda<br/>(FastAPI / Mangum)]
    end

    subgraph Data_Layer [Data & Vector Store]
        Aurora[Aurora Serverless v2<br/>(PostgreSQL + pgvector)]
        Secrets[Secrets Manager]
    end

    subgraph AI_Services [Managed AI Services]
        Bedrock[AWS Bedrock<br/>(Claude 3.5 Sonnet)]
        SageMaker[SageMaker Serverless<br/>(Embeddings)]
        Polly[AWS Polly<br/>(TTS)]
        Transcribe[AWS Transcribe<br/>(STT)]
    end

    User -->|HTTPS| CF
    CF --> S3
    CF -->|API Calls| APIGW
    APIGW --> Lambda

    Lambda -->|Relational + Vector Data| Aurora
    Lambda -->|Get Credentials| Secrets

    Lambda -->|Reasoning| Bedrock
    Lambda -->|Vector Embeddings| SageMaker
    Lambda -->|Voice Interaction| Polly
    Lambda -->|Voice Interaction| Transcribe
```

### Key Technical Decisions

- **Compute (AWS Lambda)**: Adopted for its scale-to-zero capability, eliminating costs during inactivity while handling burst traffic effortlessly.
- **Database (Aurora Serverless v2)**: Utilizes `pgvector` for high-performance vector similarity search directly within the relational database, removing the need for expensive dedicated vector stores like OpenSearch.
- **AI Orchestration (AWS Bedrock)**: Direct integration with Claude 3.5 Sonnet ensures enterprise-grade reasoning without managing model infrastructure.

## 3. Core Capabilities ("The Wow Factor")

### 🎙️ Real-Time Voice Coaching Interface

Simulates a human-like counseling session using a low-latency voice pipeline.

- **Workflow**: Speech-to-Text (Transcribe) $\to$ Semantic Analysis (Bedrock) $\to$ Text-to-Speech (Polly).
- **Impact**: Enables natural, hands-free mock interviews and career planning.

### 🧠 Context-Aware RAG Engine

Implements Retrieval-Augmented Generation to ground AI responses in verified data.

- **Data Sources**: User Profile, Singapore Live Market Data (2026 Projections), SkillsFuture Framework.
- **Mechanism**: Converts queries to vector embeddings (SageMaker) and retrieves relevant context (Aurora `pgvector`) before generating answers.

### 📄 Intelligent Resume Gap Analysis

Automated parsing and skill extraction pipeline.

- **Function**: Instantly identifies discrepancies between a user's current skills and their target role requirements.
- **Output**: Actionable recommendations mapped to specific _SkillsFuture Career Transition Programme_ (SCTP) courses.

## 4. Financial Engineering & Cost Optimization

A primary engineering challenge was optimizing for a strict budget without compromising specific enterprise features.

| Cost Component    | Enterprise Roadmap (ECS + OpenSearch) | Capstone Serverless (Lambda + pgvector) | Reduction |
| :---------------- | :------------------------------------ | :-------------------------------------- | :-------- |
| **Compute**       | ~$70/mo (Idle Fargate Instances)      | **$0/mo** (Pay-per-request)             | 100%      |
| **Vector Search** | ~$700/mo (OpenSearch Min. Provision)  | **$0/mo** (Integrated in DB)            | 100%      |
| **Database**      | ~$45/mo (Aurora Min. ACU)             | ~$45/mo (Aurora Min. ACU)               | 0%        |
| **Total Est.**    | **~$815 / month**                     | **~$45 / month**                        | **~95%**  |
